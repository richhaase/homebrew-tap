# Homebrew Taps by richhaase

This repository contains Homebrew formulas for installing my tools.

## Installation

```bash
brew tap richhaase/tap
brew install plonk
````

Available Formulas

plonk

The unified package and dotfile manager for developers who tinker.

brew install richhaase/tap/plonk

For more information about plonk, visit: https://github.com/richhaase/plonk

How This Tap Works

This tap is automatically updated by https://goreleaser.com whenever a new version of a tool is released.
The formulas are generated with proper checksums and platform support.
